# Zynq_ZC706_HDMI

HDMI display pipeline implementation on the Xilinx Zynq-7000 ZC706 Evaluation Kit.

This project demonstrates how image/frame data stored in **DDR memory** can be read by the programmable logic and transmitted to an HDMI display through the onboard **ADV7511 HDMI transmitter**.

**Current Status:** The HDMI display pipeline is functional. For the current version, frame/test-pattern data is written into DDR through **Vitis software**. Direct integration with an operating-system framebuffer is planned for a future version.

Project Overview : 

The objective of this project is to develop an HDMI video output pipeline using the **Zynq-7000 Processing System (PS)** and **Programmable Logic (PL)**.

Objective :

The main objectives of this project are:

* Read video/frame data stored in DDR memory.
* Transfer the frame data from DDR to the video processing pipeline.
* Convert the memory data into an AXI4-Stream video format.
* Generate the required video timing.
* Configure the HDMI transmitter through I2C.
* Output the video through the ZC706 HDMI interface.
* Verify HDMI display functionality before integrating the pipeline with an operating system.

Hardware :

### Development Board

**Xilinx ZC706 Evaluation Kit**

The ZC706 is based on the **Zynq-7000 XC7Z045 SoC**, which combines:

* ARM Processing System (PS)
* Programmable Logic (PL)
* DDR memory interface
* High-speed interfaces
* HDMI connectivity

### HDMI Transmitter

The ZC706 board uses the **Analog Devices ADV7511** HDMI transmitter.

The ADV7511 receives the video data and timing signals and converts them into an HDMI output signal.

Data Flow :

The current implementation follows the sequence below.

### 1. Generate Frame Data

A test pattern/frame is generated by the **Vitis application**.

### 2. Write Frame Data to DDR

The Vitis application writes the frame data into the DDR memory connected to the Zynq Processing System.

Vitis Application
       │
       ▼
Zynq PS
       │
       ▼
DDR Memory

### 3. Read Frame Data

The **Frame Read Buffer IP** accesses the DDR memory through the AXI memory-mapped interface.

DDR Memory
    │
    ▼
Frame Read Buffer

### 4. Convert to Video Stream

The frame data is converted into an **AXI4-Stream video format** and passed through the video processing pipeline.

Frame Read Buffer
       │
       ▼
Sub Converter
       │
       ▼
AXI4-Stream Video

### 5. Generate Video Timing

The **Video Timing Controller (VTC)** generates the required timing signals for the selected video resolution and frame rate.

The **AXI4-Stream to Video Out** block converts the AXI4-Stream video data into the required video output interface.

### 6. Configure HDMI Transmitter

The **ADV7511** HDMI transmitter is configured through the **I2C/IIC interface**.

Zynq PS
  │
  │ I2C
  ▼
ADV7511

### 7. HDMI Output

Finally, the ADV7511 transmits the video through the HDMI connector on the ZC706 board.

DDR Frame
    │
    ▼
Frame Read Buffer
    │
    ▼
Video Pipeline
    │
    ▼
ADV7511
    │
    ▼
HDMI Monitor

Build Flow :

### Step 1 — Create Vivado Project

Create a Vivado project targeting the ZC706 board/device.

### Step 2 — Create Block Design

Add and configure the required IPs:

* Zynq Processing System
* Frame Read Buffer
* AXI Interconnect
* Sub Converter
* AXI4-Stream to Video Out
* VTC
* IIC
* Required clock/reset infrastructure

### Step 3 — Configure Zynq PS

Configure the Processing System according to the ZC706 hardware design requirements, including the DDR interface and required PS peripherals.

### Step 4 — Connect AXI Interfaces

Connect the AXI memory-mapped interfaces between the PS, DDR and Frame Read Buffer.

Connect the AXI4-Stream interfaces through the video pipeline.

### Step 5 — Configure Video Timing

Configure the VTC and video pipeline for the desired HDMI resolution and timing parameters.

### Step 6 — Configure I2C

Connect the IIC controller to the ADV7511 interface and configure the required HDMI transmitter registers.

### Step 7 — Generate Bitstream

Run:

```text
Validate Design
        ↓
Synthesis
        ↓
Implementation
        ↓
Generate Bitstream
```

### Step 8 — Export Hardware

Generate the hardware platform/XSA file for use with Vitis.

### Step 9 — Create Vitis Application

Create a Vitis application for the Zynq Processing System.

The application is responsible for preparing the test frame and writing the frame data into DDR memory.

### Step 10 — Program the Board

Program the FPGA and run the Vitis application.

The frame data should then be read from DDR and displayed through the HDMI output.
